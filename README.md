# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my profile, skills, services, projects, experience, and contact information in a responsive and visually appealing design.

## ✨ Features

- **Home Section** – Introduction and developer profile.
- **About Me** – Personal information and professional summary.
- **Skills Section** – Displays technical skills with progress bars.
- **Services Section** – Highlights web design and web development services.
- **Experience Section** – Showcases professional experience and development journey.
- **Portfolio Section** – Displays projects with interactive icons.
- **Contact Section** – Provides contact information and a contact form.
- **Google Maps Integration** – Displays a map in the contact section.
- **Custom Cursor** – Includes custom cursor elements for an enhanced browsing experience.
- **Social Media Links** – Provides links to social media profiles.
- **Responsive Navigation** – Navigation menu for moving between website sections.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Interactive functionality and custom cursor behavior.
- **Font Awesome 6** – Icons for navigation, services, social media, and contact details.
- **Google Maps Embed** – Location integration in the contact section.
