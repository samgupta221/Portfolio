# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my profile, technical skills, services, experience, projects, and contact information through a clean and visually appealing interface.

## 👩‍💻 About Me

Hi, I'm **Samridhi Gupta**, a B.Tech Computer Science graduate and Front-End Developer passionate about creating interactive, responsive, and user-friendly web experiences.

This portfolio highlights my development journey, technical expertise, and selected projects.

## ✨ Features

- **Home Section:** Introduction and personal profile.
- **About Me:** Professional introduction and personal details.
- **Skills Section:** Technical skills represented through progress bars.
- **Services Section:** Web Design and Web Development services.
- **Experience Section:** Timeline-based experience and development journey.
- **Portfolio Section:** Project gallery with interactive icons.
- **Contact Section:** Contact information and message form.
- **Social Media Links:** Quick access to social profiles.
- **Google Maps Integration:** Embedded map in the contact section.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling, layouts and animations |
| JavaScript | Interactive functionality |
